# macOS Utilities (`mac-utility/`)

Lightweight native utilities and menu bar tools for macOS setups.

- **[vorssaint-utils](https://github.com/vorssaint/vorssaint-utils)** — Native Swift macOS menu bar toolkit (keep-awake, system monitor, volume mixer, window management, clipboard history).
  - **Install (Homebrew):** `brew install --cask vorssaint`
